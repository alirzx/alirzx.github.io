# Alireza Hashemi Portfolio

Personal portfolio website for Alireza Hashemi, focused on AI engineering, machine learning, computer vision, medical AI, NLP/LLM systems, selected publications, awards, and applied research projects.

## Structure

- `index.html` - landing page and primary identity signal.
- `about.html` - profile, skills, interests, and certificates.
- `resume.html` - compressed professional resume.
- `portfolio.html` - project gallery with filtering.
- `portfolio-details.html` - dynamic project detail page driven by query parameters.
- `services.html` - publications overview.
- `pub*_details_page.html` - publication detail pages.
- `Awards.html` and `Awards-details*.html` - honors and award details.
- `contact.html` - contact profile and Formspree-backed contact form.
- `assets/` - images, CSS, JavaScript, and vendored frontend libraries.

## Notes

This is a static GitHub Pages site. Most pages are standalone HTML files using Bootstrap, Bootstrap Icons, AOS, Swiper, GLightbox, and Isotope.
